# GatherGlow

**Live product: https://gatherglow-two.vercel.app** (no sign-up, no login)  ·  Source: this repository (public)

**For the friend who always ends up organizing.** Everyone in the group adds their day (work, study, busy time), what they'd love to do and a private budget. GatherGlow finds the hours you all share and builds three plans across real New York City venues and events, priced with NYC tax and tip, inside everyone's budget. The group votes, the organizer locks a plan and books.

- **Who pays:** consumers only. Free: 1 group plan a month (up to 6 people, no AI). **Event Pass** $7.99 one-time (one plan, AI, up to 12). **Plus** $9.99/month or $79/year (one organizer). **Family** $19.99/month or $159/year (up to 6 in a household). **Crew** $24.99/month or $199/year (a friend group of up to 8; everyone can start plans and use AI). People you invite never pay.
- **Market:** B2C, New York City, working adults 25–45.

## For judges (about 5 minutes)

1. Open **https://gatherglow-two.vercel.app**. Click **Start planning** (or **Try with a sample group** to start with 3 sample friends). No sign-up.
2. Make your planet: name, food, interests, busy times (typed into a popup), wishes, private budget.
3. In **Your crew**, click **Open as a second person ↗**. A new tab opens as a different person. Join with different times and a different budget.
4. The first tab updates live. Click **Bring everyone together**, drag the planets in, and see three plans drawn on a 3D Manhattan.
5. Vote and comment in both tabs. The plan's creator locks the top plan and books (simulated codes).
6. **Come back:** open **My plans** in the header: your plans, the friends you plan with, outings booked and money kept under budget. Your planet is pre-filled in the next plan, and **Remind me in 4 weeks** downloads a calendar reminder.
7. **Paywall:** click **Ask AI to organize**, create a second plan in the same month, or open **Pricing**. Choose Event Pass, Plus, Family or Crew. Pay with Stripe test card `4242 4242 4242 4242`, any future date, any CVC. Plus unlocks, and the AI organizer runs on Claude.

## Live data, ratings and changes

- **Live events, three sources:**
  - **NYC Parks** (official public-events feed, no key needed, next 14 days): free tours, art, nature, history, concerts in parks, with times, coordinates, official photos and RSVP links. Always on.
  - **SeatGeek** (`SEATGEEK_CLIENT_ID`, free at seatgeek.com/account/develop): ticketed concerts, comedy and theater with lowest price, image and a Buy tickets link.
  - **Ticketmaster** (`TICKETMASTER_API_KEY`, developer.ticketmaster.com): same, from Ticketmaster.
  Results are cached for 30 minutes. Free events get their own "Free events that day" group; paid events join Concerts & shows.
- **Price and delay alerts:** when a locked plan contains a live event, the server re-checks it at the source at most every 15 minutes while anyone has the plan open. Price, time, date or status changes (postponed, rescheduled, cancelled, or no longer listed by NYC Parks) become alerts that every member sees (Alerts button, pop-up, and a browser notification if they turned it on).
- **Ratings and reviews:** people rate each stop after a booked outing; cards show the GatherGlow average and a "most wished" rank, both computed from real usage. Set `GOOGLE_PLACES_API_KEY` (Places API, New) to also show Google star ratings and three recent Google reviews (cached 7 days). Nothing is shown when there is no data.
- **Real photos:** `public/js/photos.js` holds Wikimedia Commons photos for every venue, credited in the detail view.
- **Changing a booked plan:** members can say "I can't make it" or edit their times (the group gets an alert). The organizer can reopen the plan: free with Plus/Family/Crew, one free change with an Event Pass, otherwise $2.99 per change (Stripe).

## How it works

- **Planner (our code, `public/js/app.js`):** merges everyone's timetables into shared free windows, filters venues by date, season, opening hours, age and diet, places stops with travel time (walk under 1.3 km, else subway estimate), prices the group total, and ranks plans by wishes covered, interests matched and cost. Nothing is hardcoded per group.
- **AI organizer (`api/index.py`, Claude `claude-opus-5-5`):** gets the shared free windows, the available venues and each person's wishes, plus only the group's lowest budget. Every AI plan is re-checked by our code against timetables, opening hours, start times and travel before it is shown.
- **Privacy:** budgets are stored server-side. Each person sees only their own budget; the group sees only the lowest limit. The AI never sees individual budgets.
- **Identity without sign-up:** each browser gets a random token; the plan link is the invite. `?fresh=1` gives a tab its own identity (used by "Open as a second person").
- **Sync:** every open tab polls the plan every few seconds, so joins, votes, comments, suggestions, locks and bookings show up for everyone.
- **Retention:** each browser keeps a list of its plans and its last planet on the server (`idx:` and `prof:` keys). The home screen greets returning users with their last plan; a calendar reminder (.ics with an alert) nudges the next outing.
- **Payments:** Stripe Checkout in test mode: subscriptions (monthly/yearly) and a one-time Event Pass. Family/Crew cover the first 5/7 people who join the subscriber's plans. The return page verifies the session server-side before unlocking Plus.

## Run locally

Requires Python 3.9+.

```bash
pip install -r requirements.txt
cp .env.example .env        # optional: add keys to test payments and AI
python3 dev_server.py       # http://localhost:3000
```

Without Supabase keys, local runs store data in `.data/store.json`. Without a Stripe key the paywall shows "not configured"; without an Anthropic key the AI organizer is unavailable. Everything else works.

## Deploy (Vercel + Supabase + Stripe test mode + Anthropic)

1. **Supabase:** create a project, run `supabase/schema.sql` in the SQL editor, copy the project URL and the `service_role` key.
2. **Stripe:** in test mode, copy the secret key (`sk_test_...`). No products need to be created; the price is set in code.
3. **Anthropic:** create an API key at console.anthropic.com.
4. **Vercel:** import this GitHub repo. Add environment variables `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `STRIPE_SECRET_KEY`, `ANTHROPIC_API_KEY`. Deploy.
5. Open `/api/health` on the deployment. It should show `"store": "supabase"`, `"stripeMode": "test"` and `"ai": true`.
